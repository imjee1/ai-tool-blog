오늘 Hacker News는 거대 AI 모델 발표보다는 "에이전트를 실제로 어떻게 다루고, 이해하고, 로컬에서 굴려볼 것인가"에 관한 실용적인 이야기들이 많았다. 메타가 새로운 개인 AI 에이전트를 공개했고, 개발자들은 코딩 에이전트의 산만함을 잡는 스킬부터 초거대 모델을 맥북에서 굴리는 실험까지 다양한 시도를 공유했다.

## I-have-ADHD: 코딩 에이전트가 답을 묻어버리지 않게 하는 스킬

코딩 에이전트를 쓰다 보면 긴 사고 과정 끝에 정작 중요한 결론이나 답변이 장황한 텍스트 사이에 묻혀버리는 경우가 많다. 이 프로젝트는 그런 문제를 막기 위해 에이전트가 핵심 답변을 명확하게 앞이나 눈에 띄는 곳에 드러내도록 유도하는 스킬(프롬프트 패턴)을 제공한다. 이름부터 유머러스하지만 실제로 많은 개발자들이 공감하는 실용적인 문제를 다뤘다는 점에서 댓글 반응이 뜨거웠다.

에이전트 출력의 가독성 문제는 다들 겪어봤을 법한 현실적인 페인포인트라 주목할 만하다.

https://github.com/ayghri/i-have-adhd

## Muse – 메타의 개인 AI 에이전트

메타가 공개한 Muse는 개인화된 AI 에이전트로, 사용자의 맥락을 이해하고 다양한 작업을 도와주는 것을 목표로 한다. 공식 소개 페이지에서는 일상적인 업무 보조부터 개인 비서 역할까지 폭넓은 활용 사례를 제시하고 있다. 빅테크가 개인화 에이전트 시장에 본격적으로 뛰어들고 있다는 신호로 읽을 수 있다.

메타의 에이전트 전략이 구글, OpenAI와 어떻게 차별화될지 지켜볼 필요가 있다.

https://ai.meta.com/muse/

## Kimi K3 (2.8T), 맥북 프로에서 SSD 4개로 스트리밍하며 1 token/s

Kimi K3라는 2.8조 파라미터급 모델을 맥북 프로 한 대에서, 그것도 SSD 4개에 모델을 분산 저장하고 스트리밍하며 초당 1토큰 속도로 구동한 실험이다. 메모리에 다 올릴 수 없는 초거대 모델을 저장장치 대역폭을 활용해 억지로 돌려본 하드코어한 시도로, 실용성보다는 "가능한가"를 증명하는 실험에 가깝다. 속도는 느리지만 개인 하드웨어에서 조단위 파라미터 모델을 돌릴 수 있다는 것 자체가 흥미로운 포인트다.

로컬 LLM 실행의 한계를 어디까지 밀어붙일 수 있는지 보여주는 사례라 주목할 만하다.

https://github.com/argonautlabsai/deltafin

## Show HN: LLM Attention Visualization

트랜스포머 모델의 어텐션 메커니즘을 시각적으로 살펴볼 수 있는 도구다. 토큰 간 어텐션 가중치가 어떻게 분포하는지를 인터랙티브하게 확인할 수 있어, LLM 내부 동작을 직관적으로 이해하는 데 도움을 준다. 댓글 수 대비 관심도가 높았던 것을 보면 LLM 내부 구조에 대한 개발자들의 궁금증이 여전히 크다는 걸 알 수 있다.

블랙박스처럼 여겨지는 LLM 동작을 눈으로 확인하고 싶은 개발자에게 유용한 도구다.

https://ishamf.dev/p/llm-attention-visualizer/

## Multi-Agents LLM Financial Trading Framework

여러 개의 LLM 에이전트가 역할을 나눠 협업하며 금융 트레이딩 전략을 시뮬레이션하는 오픈소스 프레임워크(TradingAgents)다. 애널리스트, 리서처, 트레이더 등 실제 트레이딩 데스크의 역할 분담을 에이전트 구조로 재현한 것이 특징이다. 멀티 에이전트 아키텍처를 실제 도메인 문제에 적용한 사례로서 참고할 만하다.

에이전트 협업 설계 패턴을 실전 도메인에 적용하고 싶은 개발자에게 참고가 될 만하다.

https://github.com/TauricResearch/TradingAgents

## The VMs Powering Mobile Agents (Instinct, Claude Code)

모바일 환경에서 동작하는 AI 에이전트(Instinct, Claude Code 등)들이 실제로 어떤 가상머신·인프라 구조 위에서 동작하는지를 분석한 글이다. 에이전트가 코드를 실행하거나 명령을 처리할 때 필요한 샌드박스 환경을 어떻게 구성하는지 다룬다. 에이전트 제품의 화려한 UI 뒤에 있는 인프라 설계를 들여다볼 수 있어 흥미롭다.

에이전트 프로덕트를 직접 만들고 싶은 개발자라면 인프라 설계 측면에서 참고할 부분이 많다.

https://rohanadwankar.github.io/posts/platforms.html
