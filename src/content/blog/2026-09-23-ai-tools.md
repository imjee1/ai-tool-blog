오늘은 앤스로픽과 오픈AI가 나란히 신모델을 공개하면서 Hacker News가 온통 두 회사 이야기로 뒤덮인 날이었습니다. 그 외에도 gzip으로 언어 모델을 만들 수 있는지에 대한 재미있는 실험, 단종된 FoxPro의 부활, WordPress의 심각한 보안 취약점까지 다양한 주제가 눈에 띕니다.

## Claude Opus 5.5

앤스로픽이 Claude Opus 5.5를 공개했습니다. HN에서는 두 개의 서로 다른 스레드에 걸쳐 총 1400점 이상, 800개 가까운 댓글이 달릴 정도로 뜨거운 반응을 얻었습니다. 구체적인 벤치마크나 개선 사항에 대한 논쟁이 활발하게 오갔습니다.

같은 날 GPT-6와 정면 비교되며 개발자들 사이에서 어느 모델이 실제 코딩/추론 작업에 더 나은지에 대한 실사용 후기가 쏟아지고 있어 주목할 만합니다.

- https://www.anthropic.com/claude-opus-5-5
- 토론: https://news.ycombinator.com/item?id=49803892 / https://news.ycombinator.com/item?id=49803863

## GPT-6 Sol and Luna

오픈AI는 GPT-6를 "Sol"과 "Luna" 두 가지 버전으로 나눠 공개했습니다. 이름에서 짐작할 수 있듯 용도나 성능 특성이 다른 두 모델을 동시에 내놓은 것으로 보이며, HN에서는 590개의 댓글이 달리며 두 모델의 차이점과 실제 성능에 대한 갑론을박이 이어졌습니다.

Claude Opus 5.5와 같은 날 발표되면서 자연스럽게 두 회사의 경쟁 구도를 다시 한번 확인시켜준 이벤트입니다.

- https://openai.com/index/introducing-gpt-6-sol-and-luna/
- 토론: https://news.ycombinator.com/item?id=49805509

## Claude Opus 5.5 성능/가격 분석

Artificial Analysis가 Claude Opus 5.5(Max 버전)의 지능, 성능, 가격을 정리한 분석 자료를 내놓았습니다. 벤치마크 점수와 API 가격을 다른 모델들과 나란히 비교할 수 있어, 실제로 어떤 워크로드에 쓸지 판단할 때 참고하기 좋은 자료입니다.

발표 직후 나온 제3자 벤치마크라는 점에서 마케팅 자료보다 신뢰도 있는 데이터를 원하는 개발자들에게 유용합니다.

- https://artificialanalysis.ai/models/claude-opus-5-5
- 토론: https://news.ycombinator.com/item?id=49804316

## gzip으로 언어 모델을 만들 수 있을까

"Can gzip be a language model?"이라는 글은 gzip 같은 압축 알고리즘의 원리를 이용해 텍스트 생성이나 분류가 가능한지를 탐구합니다. 실제로 압축 기반 접근이 간단한 분류 작업에서 놀랍도록 잘 작동한다는 기존 연구들을 소개하며, 저자 나름의 실험과 해설을 곁들였습니다.

거대 신경망 없이도 압축 알고리즘만으로 언어 모델의 일부 특성을 흉내낼 수 있다는 점이 흥미로워 371점, 146개 댓글이라는 큰 관심을 받았습니다.

- https://nathan.rs/posts/gzip-lm/
- 토론: https://news.ycombinator.com/item?id=49797323

## 2007년에 죽은 FoxPro, 다시 살아나다

마이크로소프트가 2007년 단종시킨 FoxPro를 되살리려는 프로젝트 FoxScript가 공개됐습니다. 레거시 FoxPro 코드베이스를 현대 환경에서 다시 돌릴 수 있게 만드는 시도로 보이며, 오래된 시스템을 유지보수해야 하는 개발자들의 향수와 관심을 동시에 자극했습니다.

레거시 기술의 부활이라는 흔치 않은 주제로 161점, 119개 댓글이라는 의외의 호응을 얻었습니다.

- https://foxscript.org/
- 토론: https://news.ycombinator.com/item?id=49808023

## WordPress, 인증 없이 원격 코드 실행 가능한 취약점 발견

WordPress 코어에서 인증되지 않은 경로 탐색(path traversal) 취약점이 발견됐고, 특정 조건에서는 원격 코드 실행(RCE)까지 이어질 수 있다는 보안 권고가 공식 GitHub 저장소에 올라왔습니다. 전 세계 웹사이트의 상당수가 WordPress로 운영되는 만큼 파급력이 큰 이슈입니다.

WordPress를 운영 중이라면 반드시 패치 여부를 확인해야 할 사안이라 150점, 80개 댓글의 뜨거운 관심을 받았습니다.

- https://github.com/WordPress/wordpress-develop/security/advisories/GHSA-7hp8-65ch-5whp
- 토론: https://news.ycombinator.com/item?id=49803959

## LLM Ass Bench

이름부터 눈길을 끄는 "LLM Ass Bench"는 여러 LLM의 성능을 재미있는 방식으로 비교/평가하는 벤치마크 사이트입니다. 정식 학술 벤치마크라기보다는 커뮤니티 성격이 강한 실험적 프로젝트로 보이며, 기존 벤치마크들과는 다른 관점에서 모델들을 테스트해본다는 점에서 화제가 됐습니다.

딱딱한 벤치마크 문화에 유머를 더한 시도라는 점에서 138점, 39개 댓글의 호기심 어린 반응을 얻었습니다.

- https://www.assbench.com/
- 토론: https://news.ycombinator.com/item?id=49807688
