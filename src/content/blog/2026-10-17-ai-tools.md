오늘은 Anthropic의 연구 성과가 유독 눈에 띄는 날입니다. Claude Code 팀의 코드 리뷰 노하우부터 암호학·양자컴퓨팅 연구까지, Claude를 실제 업무와 연구에 어떻게 활용하는지 보여주는 사례가 많았습니다. 그 외에도 PS5 해킹으로 로컬 LLM을 돌리는 실험, Mac 화면을 iPhone으로 끌어오는 오픈소스 프로젝트, Home Assistant를 둘러싼 프라이버시 논란 등 다양한 주제가 화제를 모았습니다.

## Claude가 ECDSA 타원곡선의 숨겨진 기원을 추적하다

Anthropic 연구팀이 Claude를 활용해 NIST 표준 타원곡선(ECDSA에 쓰이는)의 숫자 파라미터가 어디서 왔는지 역사적 기원을 추적한 연구입니다. 오랫동안 암호학 커뮤니티에서는 이 "임의의 시드값"들이 어떻게 선택됐는지 불투명하다는 의혹이 있었는데, Claude가 문헌 조사와 추론을 결합해 실마리를 찾아냈습니다. AI가 수십 년 묵은 암호학 미스터리를 파고드는 방식 자체가 흥미로운 사례입니다.

→ https://www.anthropic.com/research/ecdsa-curve-origins

## Claude Code 팀은 코드 리뷰를 어떻게 하는가

Anthropic 내부에서 Claude Code를 만드는 팀이 실제로 어떤 코드 리뷰 프로세스를 쓰는지 공개한 글입니다. AI 코딩 도구를 만드는 팀일수록 리뷰 과정에 AI를 얼마나, 어떻게 섞어 쓰는지가 관심사인데, 실제 운영 경험을 바탕으로 한 구체적인 팁들이 담겨 있습니다. 댓글 200개가 넘게 달릴 정도로 개발자들의 리뷰 프로세스 개선에 대한 갈증을 보여줍니다.

→ https://claude.dev/blog/solving-code-review-at-anthropic/

## Claude로 양자 회로를 더 효율적으로 설계하기

Anthropic이 Claude를 활용해 양자 회로 설계를 최적화한 연구 결과를 공개했습니다. 양자 컴퓨팅은 회로의 게이트 수나 깊이를 줄이는 것이 성능에 직결되는데, LLM이 이런 최적화 작업에 어떻게 기여할 수 있는지를 보여주는 사례입니다. AI가 전통적으로 전문가의 직관에 의존하던 영역까지 파고드는 흐름을 확인할 수 있습니다.

→ https://www.anthropic.com/research/designing-efficient-quantum-circuits

## Gemini로 만든 "Argon"이 스타크래프트를 플레이하다

Gemini 기반 에이전트 "Argon"이 실제로 스타크래프트를 플레이하는 벤치마크 사이트입니다. 전략 게임은 장기 계획, 자원 관리, 실시간 의사결정이 복합적으로 요구되기 때문에 LLM 에이전트의 역량을 가늠하는 좋은 테스트베드로 꼽힙니다. 게임 플레이를 통해 AI의 추론 능력을 직관적으로 보여준다는 점에서 눈길을 끕니다.

→ https://starskirmish.com/bench/v0-2/

## 탈옥한 PS5에서 GGUF 모델을 네이티브로 돌리기

PS5를 탈옥해서 llama.cpp를 포팅하고, GGUF 포맷의 로컬 LLM을 콘솔에서 직접 실행하는 프로젝트입니다. 게임 콘솔의 하드웨어를 LLM 추론용으로 재활용한다는 발상 자체가 해커 정신을 잘 보여주며, 임베디드/비표준 하드웨어에서의 LLM 실행 가능성을 다시 생각하게 합니다. 실용성보다는 "되는지 안 되는지" 확인하고 싶은 엔지니어들에게 흥미로운 레퍼런스입니다.

→ https://github.com/cobanov/PS5LM

## Home Assistant, 동의 없이 시크릿을 스캔하는 통합 기능 논란

Home Assistant 사용자가 자신이 승인하지 않은 통합(integration)이 설정 파일의 시크릿 값을 스캔하고 있었다는 사실을 발견하고 올린 이슈입니다. 오픈소스 홈 자동화 플랫폼에서도 서드파티 통합의 권한 범위와 투명성 문제가 불거진 사례로, 댓글에서 128개의 활발한 토론이 이어졌습니다. AI 기능 확장과 맞물려 통합 생태계의 보안 모델을 다시 점검해야 한다는 목소리가 나옵니다.

→ https://github.com/home-assistant/home-assistant.io/issues/49314

## Anthropic Console, 국제화 입력 버그로 카드 100배 과금 사고

한 사용자가 Anthropic Console에서 결제 금액 입력 시 국제화(i18n) 처리 버그로 인해 카드가 100배 과다 청구됐다고 보고한 사례입니다. 소수점 구분 기호(쉼표 vs 마침표) 같은 로케일 처리 실수가 실제 금전 피해로 이어질 수 있다는 점을 보여주는 사례입니다. 결제 시스템을 다루는 개발자라면 한 번쯤 자신의 입력 검증 로직을 점검해볼 만한 계기입니다.

→ https://news.ycombinator.com/item?id=50121562

## 덤으로, Mac 화면을 iPhone/iPad로 그대로 가져오기

Mac의 특정 윈도우를 iPhone이나 iPad 화면으로 실시간 스트리밍해주는 오픈소스 프로젝트 "Sill"입니다. 애플 생태계 안에서 멀티 디바이스 작업 흐름을 개선하려는 시도로, AI 주제는 아니지만 개발자들의 실질적인 생산성 도구로 많은 관심을 받았습니다.

→ https://github.com/Saffsanity/sill
