오늘 Hacker News는 AI를 "어떻게 더 잘 쓸 것인가"와 "어떤 하드웨어로 돌릴 것인가"라는 두 축으로 나뉘었습니다. 애플이 유휴 기기를 묶어 GPU 클라우드를 만드는 연구를 공개했고, 개인 개발자는 SSD에서 전문가 모델을 스트리밍해 RAM보다 큰 LLM을 돌리는 프로젝트를 선보였습니다. 동시에 "AI는 도구일 뿐이고 잘 쓰려면 숙련도가 필요하다"는 에세이와 게임 개발에 Claude Code를 활용한 실전 사례가 큰 공감을 얻었습니다.

## AI is a tool and using it well takes skill
AI 코딩 도구를 둘러싼 "만능이다 vs 쓸모없다"는 이분법적 논쟁에 반기를 드는 글입니다. 저자는 AI를 잘 쓰는 것도 하나의 숙련된 기술이며, 프롬프트 설계, 컨텍스트 관리, 결과 검증 등 체계적인 역량이 필요하다고 주장합니다. 511개의 댓글이 달릴 정도로 "AI 생산성"에 대한 개발자들의 온도차를 잘 보여주는 글입니다.
→ AI 도구 논쟁이 성숙 단계로 접어들고 있음을 보여주는 사례라 주목할 만합니다.
https://yyhh.org/blog/2026/10/ai-is-a-tool/

## A Dynamic and Distributed Virtual GPU Cloud Built on Idle Apple Silicon Devices
애플 머신러닝 연구팀이 발표한 연구로, 사용하지 않는 애플 실리콘 기기(맥, 아이패드 등)들을 묶어 가상 GPU 클라우드를 구성하는 접근법을 다룹니다. 유휴 연산 자원을 동적으로 할당해 분산 추론/학습 워크로드를 처리하는 아키텍처를 제시했습니다. 아직 연구 단계지만 애플이 자체 하드웨어 생태계를 AI 인프라로 활용하려는 방향성을 엿볼 수 있습니다.
→ 클라우드 GPU 의존도를 낮추려는 빅테크의 전략을 보여주는 신호라 흥미롭습니다.
https://machinelearning.apple.com/research/distributed-gpu-cloud

## Janas: Run LLMs larger than RAM by streaming experts from SSD
MoE(Mixture of Experts) 구조의 LLM에서 활성화되는 전문가(expert) 레이어만 SSD에서 실시간으로 스트리밍해, RAM 용량을 초과하는 거대 모델도 로컬에서 구동할 수 있게 한 오픈소스 프로젝트입니다. 메모리 제약이 있는 환경에서 대형 모델을 돌릴 수 있는 실용적인 접근으로, 86개의 댓글에서 성능과 지연시간에 대한 실측 토론이 활발했습니다.
→ 로컬 LLM 구동의 하드웨어 장벽을 낮추는 실용적인 시도라 개발자들의 관심이 높습니다.
https://github.com/prabanta-dev/janas

## How to engineer an AI harness for game development
게임 개발에 Claude Code를 활용하기 위해 저자가 구축한 "AI 하네스"(작업 지시, 검증, 반복 루프를 자동화하는 프레임워크) 구축 경험기입니다. 단순히 프롬프트를 던지는 수준을 넘어, AI가 반복적으로 코드를 생성·테스트·수정하는 구조를 어떻게 설계했는지 구체적으로 설명합니다. 실제 프로덕션 워크플로우에 AI 에이전트를 통합하려는 개발자에게 실질적인 참고 사례가 됩니다.
→ "AI 도구를 잘 쓰는 법"에 대한 구체적 엔지니어링 답변이라는 점에서 눈여겨볼 만합니다.
https://kylekukshtel.com/ai-harness-engineering-game-development-claude-code
