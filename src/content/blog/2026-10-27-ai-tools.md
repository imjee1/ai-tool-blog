오늘 Hacker News는 새 플래그십 모델 공개와 그로 인한 가격 경쟁, 그리고 그 아래에서 드러나는 인프라·보안 문제들로 채워졌습니다. 모델 성능 경쟁이 가격 경쟁으로 번지는 동시에, vLLM 툴콜 정확도나 KV 캐시 노출 같은 "실전에서 터지는" 문제들도 함께 주목받았습니다. 여기에 AI가 채용·고용 구조를 흔드는 사례까지 더해지면서, 기술과 조직 양쪽에서 변화의 속도를 체감할 수 있는 날이었습니다.

## GPT-6.1 Terra 공개

OpenAI가 새로운 모델 "GPT-6.1 Terra"를 발표했습니다. HN에서 497점, 댓글 314개로 오늘 가장 뜨거운 토론을 이끌었는데, 새 모델이 나올 때마다 반복되는 성능 검증과 실사용 후기 논쟁이 이어지고 있습니다. 플래그십 모델 공개 자체보다, 커뮤니티가 실제로 무엇을 검증하고 어떤 부분에 의문을 제기하는지가 더 흥미로운 지점입니다.

원문: https://openai.com/index/introducing-gpt-6-1-terra/

## OpenAI와 Anthropic, 몇 달 새 가격을 최대 80% 인하한 이유

OpenAI와 Anthropic이 최근 몇 달 사이 LLM API 가격을 최대 80%까지 낮췄습니다. 이 글은 단순 경쟁 심화를 넘어, 추론 비용 구조 변화와 모델 효율화, 시장 점유율 확보 전략 등 복합적인 원인을 분석합니다. 가격 인하 추세는 API를 활용해 서비스를 만드는 개발자들의 비용 구조와 제품 설계 방식에도 직접적인 영향을 줄 수 있어 주목할 필요가 있습니다.

원문: https://minimaxir.com/2026/10/cheap-llms/

## Exponential Time Hypothesis is False (PDF)

OpenAI의 수학 연구 리포지토리에 올라온 논문으로, 복잡도 이론의 오랜 가정인 "지수 시간 가설(ETH)"이 거짓임을 주장하는 내용입니다. 이 가설은 SAT 문제 등 다양한 NP-난해 문제의 하한을 증명하는 데 널리 쓰여온 기반이라, 사실이라면 이론 전산학 전반에 파장이 클 수 있습니다. AI 기업이 순수 수학 난제에 리소스를 투입하고 있다는 점 자체도 눈여겨볼 만합니다.

원문: https://github.com/openai/math/blob/main/preprints/The-Exponential-Time-Hypothesis-is-False-October-25-2026/paper.pdf

## Type Server Protocol

Microsoft Pylance 팀이 "Type Server Protocol(TSP)"이라는 새로운 프로토콜 문서를 공개했습니다. LSP(Language Server Protocol)가 에디터와 언어 서버 간 통신을 표준화했듯, TSP는 타입 정보 교환을 전담하는 별도 프로토콜로 보입니다. 여러 도구가 타입 체커를 공유·재사용할 수 있는 표준이 생긴다면 Python을 비롯한 동적 타입 언어의 생태계에 실질적인 이점이 될 수 있습니다.

원문: https://github.com/microsoft/pylance-release/blob/main/docs/tsp/type-server-protocol.md

## vLLM의 Tool-Call 정확도 문제 해결하기

Ubicloud 팀이 vLLM에서 함수 호출(tool call) 정확도가 떨어지는 문제를 분석하고 수정한 과정을 공유했습니다. 에이전트 기반 애플리케이션이 늘어나면서 모델이 올바른 포맷으로 도구를 호출하는지가 점점 중요한 품질 지표가 되고 있습니다. 자체 추론 인프라를 운영하는 팀이라면 실무에 바로 참고할 만한 디버깅 사례입니다.

원문: https://www.ubicloud.com/blog/fixing-tool-call-accuracy-in-vllm

## Cloudflare GLM-5.3 Workers AI의 KV 캐시 노출 문제

Cloudflare는 자사 Workers AI에서 서빙하던 GLM-5.3 모델에서 서로 다른 요청 간 KV 캐시가 노출될 수 있는 취약점을 발견하고 조치한 과정을 공개했습니다. KV 캐시 공유는 추론 성능 최적화에 자주 쓰이는 기법인데, 격리가 제대로 되지 않으면 다른 사용자의 요청 내용이 유출될 위험이 있습니다. 멀티테넌트 LLM 서빙 인프라를 구축하는 모든 팀이 눈여겨봐야 할 보안 사례입니다.

원문: https://blog.cloudflare.com/kv-cache-exposure-remediation/
