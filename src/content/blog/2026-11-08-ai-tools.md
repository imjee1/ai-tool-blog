오늘은 AI 코딩 에이전트의 보안 허점이 가장 뜨거운 화제였다. 동시에 GPU 공급난이 다시 수면 위로 올라왔고, 경량화된 비디오 생성 모델과 "CSS로 GPT-2 구현하기" 같은 기발한 프로젝트도 눈에 띄었다. 전반적으로 AI 도구를 실무에 들여놓을 때 생기는 부작용에 대한 관심이 커지는 분위기다.

## Claude Code의 "Don't Ask Again"이 비밀번호를 유출시키다

Apiiro 보안 연구팀이 Claude Code의 "다시 묻지 않기" 기능이 공개 GitHub 저장소 1,122개에서 비밀번호와 민감 정보를 그대로 노출시킨 사례를 발견했다. 이 옵션을 켜면 에이전트가 파일 접근이나 명령 실행 시 매번 확인받지 않고 자동으로 진행하는데, 그 과정에서 `.env` 파일이나 자격 증명이 커밋에 포함되는 일이 반복적으로 발생한 것이다. AI 코딩 에이전트에게 편의 기능을 얼마나 신뢰할지, 그리고 조직 차원의 가드레일이 얼마나 필요한지를 보여주는 사례다.

- https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again

## 슈퍼마켓 냉장고 컨트롤러로 위장한 허니팟, Coldframe

Coldframe은 산업용 냉장고 컨트롤러처럼 보이도록 설계된 허니팟 프로젝트다. 실제 냉장 설비 제어 시스템의 프로토콜과 인터페이스를 모방해 공격자를 유인하고, 접근 시도를 기록해 산업제어시스템(ICS) 대상 공격 패턴을 연구할 수 있게 해준다. IoT·ICS 보안에 관심 있는 개발자라면 가볍게 띄워볼 만한 흥미로운 사례다.

- https://github.com/hedgerow-dev/coldframe

## GitHub, 새로운 PR 개요 페이지 공개 프리뷰 시작

GitHub가 풀 리퀘스트 개요 페이지를 새 디자인으로 개편해 퍼블릭 프리뷰로 공개했다. 리뷰 상태, 체크 결과, 변경 통계 등을 한눈에 파악하기 쉽게 재구성한 것이 핵심이다. 매일 PR을 다루는 개발자라면 워크플로우에 바로 영향을 주는 변화이니 눈여겨볼 만하다.

- https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview/

## 31B 비디오·오디오 디퓨전 모델을 14B로, 6스텝 INT8까지 압축

Hyperflow-H3-Flash 프로젝트는 310억 파라미터 규모의 비디오+오디오 생성 디퓨전 모델을 140억 파라미터로 줄이고, 추론 스텝을 6단계로 단축했으며 INT8 양자화까지 적용했다. 모델 경량화를 통해 소비자용 하드웨어에서도 비디오 생성 모델을 돌릴 수 있는 가능성을 보여준다. 거대 모델을 실용적인 크기로 압축하는 최근 흐름을 잘 보여주는 사례다.

- https://github.com/Video-Rebirth/hyperflow-h3-flash

## "*sshole, 우리는 언제쯤 C를 버릴 것인가"

OpenSSH 관련 보안 이슈를 계기로, 수십 년째 시스템 프로그래밍 언어로 쓰이는 C의 메모리 안전성 문제를 다시 짚는 글이다. 저자는 Rust 등 메모리 안전 언어로의 전환이 왜 더딘지, 그리고 레거시 코드베이스의 현실적인 제약을 함께 다룬다. AI 코드 생성이 늘어나는 시대에 기반 언어의 안전성 문제는 더 중요해지고 있다는 점에서 되짚어볼 만하다.

- https://sunshowers.io/posts/sshole/

## 눈 깜빡임 리듬을 관리해주는 오프라인 데스크톱 앱

EyesRhythm은 화면을 오래 보는 사람들을 위해 눈 깜빡임 주기를 상기시켜주는 오프라인 데스크톱 컴패니언 앱이다. 클라우드 연결 없이 로컬에서 동작하며 가벼운 알림으로 안구건조를 예방하는 데 초점을 맞췄다. 개발자처럼 모니터 앞에 오래 머무는 직군에게 실용적인 작은 도구다.

- https://eyesrhythm.com/

## CSS만으로 GPT-2 구현하기

순수 CSS(선택자와 애니메이션 트릭 활용)만으로 GPT-2의 동작을 시뮬레이션한 실험적 프로젝트다. 실제 추론 성능을 위한 것이 아니라, CSS의 튜링 완전성을 보여주기 위한 기술적 유희에 가깝다. 실용성보다는 "이런 것도 되는구나"하는 재미로 가볍게 읽기 좋은 글이다.

- https://shubhampatil.dev/blog/gpt2-css
