## Postman, 동의 없이 AI 플러그인 설치하고 API 데이터 공유 시도

Postman이 사용자 동의 없이 AI 관련 플러그인을 자동 설치하고, 저장된 API 요청·응답 데이터를 외부로 공유하려 시도한 정황이 GitHub 이슈로 공개되며 큰 논란이 됐다. 특히 민감한 API 키나 내부 엔드포인트 정보가 포함될 수 있다는 점에서 보안 우려가 크다. 348개에 달하는 댓글 대부분이 비판적 반응이며, 일부는 대체 도구로의 이전을 언급하고 있다.

API 테스트 도구를 신뢰 기반으로 써온 개발자라면 반드시 확인해볼 만한 이슈다.

🔗 https://github.com/postmanlabs/postman-app-support/issues/14370

## OpenAI, Codex 대화 학습 재활성화 논란

OpenAI가 Codex 채팅 기록에 대한 모델 학습 옵트아웃 설정을 사용자 동의 없이 다시 켠 것 아니냐는 의혹이 제기됐다. 커뮤니티에서는 설정 화면과 실제 동작이 불일치한다는 증언이 다수 올라왔다. 공식 해명은 아직 명확하지 않은 상태다.

코드와 민감한 로직을 Codex에 입력하는 개발자라면 데이터 처리 정책 변경 여부를 직접 재확인해볼 필요가 있다.

🔗 https://news.ycombinator.com/item?id=50352757

HN에서 가장 많이 추천된 유튜브 영상들을 모아 끊김 없이 재생되는 TV 채널 형태로 제공하는 서비스다. 별도 검색 없이 틀어놓기만 하면 양질의 기술 콘텐츠를 계속 볼 수 있는 구조다. 커뮤니티 큐레이션 데이터를 재가공한 간단하지만 영리한 아이디어다.

콘텐츠 발견의 피로감을 줄여주는 작은 실험으로 주목할 만하다.

## Revolut, 자체 호스팅 GLM으로 전환

핀테크 기업 Revolut이 상용 LLM API 대신 GLM을 자체 서버에 호스팅하는 방식으로 전환했다는 소식이다. 비용 절감과 데이터 통제권 확보가 주요 배경으로 언급된다. 155개의 댓글에서는 자체 호스팅 LLM의 실제 운영 난이도와 품질 트레이드오프에 대한 논쟁이 이어졌다.

대형 기업이 외부 AI API 의존도를 낮추려는 흐름을 보여주는 사례다.

🔗 https://twitter.com/guilleflorvs/status/2117379073785696395

## Gitbook 침해 사고 발생

Gitbook이 보안 침해를 당했다는 소식이 커뮤니티를 통해 공유됐다. 구체적인 침해 범위와 영향받은 데이터 종류에 대한 논의가 스레드에서 이어지고 있다. Gitbook을 사내 문서 플랫폼으로 쓰는 팀이라면 공식 공지를 주의 깊게 살펴볼 필요가 있다.

문서 플랫폼도 공격 표면이 될 수 있다는 점을 다시 일깨워준 사건이다.

🔗 https://news.ycombinator.com/item?id=50354336

## LLM은 신경망 가중치를 읽고 쓰는 데 초인적이지 않다

LLM이 신경망 가중치(weights)를 직접 해석하거나 조작하는 능력을 테스트한 결과, 기대와 달리 사람보다 특별히 뛰어나지 않다는 점을 보여주는 글이다. 저자는 가중치 자체를 텍스트처럼 다루는 실험을 통해 LLM의 "내부 구조 이해력"에 대한 과도한 기대에 의문을 제기한다. AI가 AI 자신을 이해하고 수정하는 능력에 대한 막연한 낙관론에 실증적 근거로 제동을 거는 글이다.

AI 자기 개선(self-improvement) 서사에 관심 있는 개발자라면 읽어볼 가치가 있다.

🔗 https://www.seangoedecke.com/llms-are-not-superhuman-at-reading-and-writing-neural-network-weights/
